# Saygen releases

Installers for Saygen audio plugins (Mac and Windows). Download the newest from
[Releases](https://github.com/jfritzel44/saygen-releases/releases).

## Saygen MathSynth

A synthesizer that plays math: Fibonacci, Collatz, Weierstrass and more.

- Mac (AU, VST3, standalone app): [Saygen-MathSynth-mac.pkg](https://github.com/jfritzel44/saygen-releases/releases/download/mathsynth-latest/Saygen-MathSynth-mac.pkg)
- Windows (VST3, standalone app): [Saygen-MathSynth-windows.exe](https://github.com/jfritzel44/saygen-releases/releases/download/mathsynth-latest/Saygen-MathSynth-windows.exe)
